# Character asset shortlist — publisher previews

These are actual publisher model previews, not Starfall screenshots. Checked 12 September 2026. None has been imported, retargeted or accepted in Unity yet. No purchase has been made.

| Candidate | Publisher preview | Provenance and fit | Rig/animation evidence and gap |
|---|---|---|---|

Good Stone Age props, but human/chibi proportions. | Publisher lists basic rig and one simple animation; API reports one animation. Walking/idle set and Unity import are unverified. |

Sketchfab lists CC BY but its description explicitly directs to the public-domain OpenGameArt release. Use the original OGA download if selected; inspect actual rig/clip before implementation. |

The first two use [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), requiring attribution and identification of modifications. The third's download is published as [CC0](https://creativecommons.org/publicdomain/zero/1.0/). Credit its author anyway. Source licence labels establish a research candidate, not successful Unity compatibility.

For the intended upright, ape-like humanoid, none is a perfect visual match. Do not silently present a stock cartoon monkey as the completed requested character. A selected licensed base may need altered proportions, simple hide clothing, and a real walk/idle set. That work belongs to the separate character sandbox, after display controls are verified.
