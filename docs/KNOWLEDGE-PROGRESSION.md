# Knowledge is progression — world rule

Design contract, 13 September 2026. This does not expand the current integration build or claim installed cognition, predators or combat.

A new inhabitant starts cognitively naive, with only minimal embodied abilities. It has no unjustified knowledge of local plants, animals, locations, recipes or hazards. Perception, cautious experiments, observed outcomes and communication create provenance-tracked beliefs. Confidence can rise or fall; later evidence can correct a false belief. Distinguish observations, inferences, testimony and verified death lessons. A model's pretrained knowledge is not permission to grant local knowledge or execute an action.

Unity remains the deterministic authority over movement, experiments, injury, death and crafting. Learned proposals must pass the existing action gate. Readable warning signals, avoidance and retreat, bounded animal behavior, and fair counterplay are required before hazard systems become playable. Do not spawn unavoidable lethal pressure at the refuge or make death the only way to learn.

Memory belongs to the current save/world/inhabitant. No cross-save, cross-world or other-inhabitant leakage is permitted. Verified death lessons require an explicit game rule for what survives death, provenance and consented migration; none is implemented by this document. Changing confidence must retain the underlying observation and correction history rather than silently overwriting evidence.

## Staged roadmap

| Order | Milestone | Acceptance gate | Current status |
|---|---|---|---|
| 0 | Berries, safe refuge/hearth/bedding, one living thought | Separate component and joined player evidence | Existing workstreams; not completed by this document |
| 1 | Unknown-food risk | Unknown labels, readable clues, cautious sampling/avoidance, deterministic effects and belief provenance | Planned |
| 2 | Predator perception and escape | Detectable warning, bounded pursuit, reachable retreat, fair escape tests | Planned |
| 3 | Shelter threat | Legible threat to a refuge with safe disengagement and no unavoidable spawn kill | Planned |
| 4 | Learned nonlethal deterrent | Learned fire/noise/barrier responses, bounded animals and failure feedback | Planned |
| 5 | Defensive crafting/combat | Only after earlier gates; learned barriers/stakes or other defenses, deterministic authority and fair counterplay | Planned |

Future poisonous plants and predators may injure or kill. Securing a refuge with fire, noise, barriers or sharpened stakes is a future learned capability. The present hearth is a contained heat/light interaction; it does not deter predators. Bedding is a rest interaction; it does not create memory or dreams yet.
