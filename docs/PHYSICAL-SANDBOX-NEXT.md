# Next playable sandbox slice

The immediate milestone is a visible fullscreen/windowed button in a separate R19 player. Character integration follows it. This document records direction, not implemented gameplay or acceptance.

The next small sandbox should use an upright, fictional ape-like Stone Age character with a following camera. The character should be able to walk, turn and interact with nearby objects. Asset selection requires an identifiable publisher, licence, inspectable rig and actual animation clips; no purchase is authorized.

Keep the existing landscape and dense trees static. Add three distinguishable movable objects with explicit, different masses: a light wooden object, a medium resource block and a heavy stone. Gravity, ground/object collisions and the response to a common push should be visible. Include one resettable tree/resource interaction if the scene supports it; preserve the frozen display tree and use a separate marked resource specimen. Reset should restore only this sandbox's transient objects and resource state, without regenerating terrain or touching old saves.

Acceptance requires the built player: a visible animated character; walk/idle transitions; following camera with usable collision handling; grounded movement against scenery; distinguishable object motion under the same interaction; and reset returning objects/resource state. Retain screenshots and runtime observations. Compilation and ray probes alone are insufficient.

Water buoyancy, swimming, richer underwater life and autonomous bot learning are separate later milestones. Current concept references establish warm desert shores, branching kokerboom forms, the blue gas giant, a distant galaxy and a sea containing fish schools, rays, coral forms and kelp-like growth. They do not establish current implementation.

The reported ability to chop all trees is user feedback about the game being viewed, not independently verified evidence of which executable implements it. No live bot connector, external training, saved-world migration or rewrite of the whole physical world belongs to this small slice.
