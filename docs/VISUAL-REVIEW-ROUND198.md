# Round198: base-water isolation, not an appearance candidate

Seven actual Unity views were rendered with one temporary shader return:
after the depth/opaque-bed transmission diagnostics and before normal,
reflection, glint, glimmer, shoreline and fog contributions, return
`half4(water,1)`. The temporary change was then removed exactly.

In independently reviewed offshore frame07, the repeated fine/parallel bands
are absent. The flat base is visibly unsuitable as a finished ocean and reveals
coarse dark depth transitions. It must not replace the ordinary material.

Together with round197's ineffective glimmer/pulse filtering, this narrows the
dominant band investigation toward the subsequent surface response (normals,
Fresnel/reflection/specular), without proving a single cause. Coarse depth
transitions are a separate visible issue. The reference requires both clear
depth and convincing moving reflections; disabling them is not acceptance.

Evidence: `evidence/milestones/coastal/round-198`, generated by
`tools/render-coastal.ps1 -Round round-198 -Width 1600`. These are isolated
Editor diagnostic views, not ordinary-player footage or a released build.
